### 🔥 Featured Projects

#### [**Link — Multi-Facility EMR**](https://github.com/kidanekalm/link-emr) *(In Development)*  
A scalable Electronic Medical Record system for Ethiopian healthcare facilities — enabling interoperable patient data management across clinics, hospitals, and labs. Built with **.NET + Next.js**.

#### [**AI-Mediated Escrow Platform**](https://github.com/kidanekalm/escrow-platform)  
A secure peer-to-peer transaction platform with real-time chat and AI-driven dispute resolution. Uses **Go (auth), Python (mediation engine), React (frontend)**.

#### [**CPU Scheduling Simulator**](https://github.com/kidanekalm/cpu-scheduler)  
An interactive web visualizer for OS scheduling algorithms (FCFS, SJF, Round Robin). Built with **vanilla JavaScript + HTML/CSS**.

#### [**Geez Document Retrieval System**](https://github.com/kidanekalm/geez-ir)  
An information retrieval system for Ge'ez texts, featuring a custom stemmer and search interface. Preserving Ethiopia’s linguistic heritage through code.
